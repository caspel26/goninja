goninja is a code-first Go framework for generating complete CRUD REST
APIs from annotated structs: routing, input/output validation,
serialization, OpenAPI, filters, pagination.

> **Status: pre-alpha.** What exists today is an early prototype, verified
> end to end against Postgres — see the project [README](https://github.com/caspel26/goninja#status)
> for the current state.

Start with [Getting Started](getting-started), then browse the guides in
the sidebar for extending a resource, auth, testing, and CLI usage.
